artbin examples

This vignette reproduces the examples from Section 3 of the artbin Stata Journal article. Each section demonstrates a different study design.

Binary outcome and comparison with published sample size

We reproduce the sample size calculation in Pocock (1983) for a 2-arm superiority trial comparing anturan with placebo in patients after a myocardial infarction. The primary outcome was death from any cause within one year. The control (placebo) arm was expected to have a 10% probability of death and the treatment arm a 5% probability, with the trial powered at 90%.

artbin infers the outcome direction from the probabilities: because the treatment arm probability (0.05) is lower than the control (0.10), the outcome is unfavourable (the trial aims to reduce the event probability).

The Wald test is used here because Pocock used the sample estimate of the null variance.

artbin(pr = c(0.1, 0.05), alpha = 0.05, power = 0.9, wald = TRUE)
#> 
#> ART - ANALYSIS OF RESOURCES FOR TRIALS
#> ------------------------------------------------------------------------------
#> A sample size program by Abdel Babiker, Patrick Royston,
#> Friederike Barthel, Ella Marley-Zagar and Ian White
#> MRC Clinical Trials Unit at UCL, London WC1V 6LJ, UK.
#> ------------------------------------------------------------------------------
#> Type of trial                         superiority
#> Number of groups                      2
#> Favourable/unfavourable outcome       unfavourable
#> Allocation ratio                      equal group sizes
#> Statistical test assumed              unconditional comparison of 2 binomial proportions
#>                                         using the wald test
#> Local or distant                      distant
#> Continuity correction                 no
#> 
#> Anticipated event probabilities       0.100  0.050
#> 
#> Alpha                                 0.050 (two-sided)
#>                                         (taken as 0.025 one-sided)
#> Power (designed)                      0.900
#> 
#> Total sample size (calculated)        1156
#> Sample size per group (calculated)    578 578
#> Expected total number of events       86.70
#> Expected number of events per group   57.80 28.90
#> ------------------------------------------------------------------------------

A total sample size of 1156 participants is required, matching the published figure. The same result is obtained using pr = c(0.9, 0.95) with a favourable outcome (survival).

One-sided non-inferiority trial

A one-sided non-inferiority trial assuming a 90% probability of survival in both arms, with the treatment arm required to be no more than 5 percentage points less effective than control.

artbin(pr = c(0.9, 0.9), margin = -0.05, onesided = TRUE)
#> 
#> ART - ANALYSIS OF RESOURCES FOR TRIALS
#> ------------------------------------------------------------------------------
#> A sample size program by Abdel Babiker, Patrick Royston,
#> Friederike Barthel, Ella Marley-Zagar and Ian White
#> MRC Clinical Trials Unit at UCL, London WC1V 6LJ, UK.
#> ------------------------------------------------------------------------------
#> Type of trial                         non-inferiority
#> Number of groups                      2
#> Favourable/unfavourable outcome       favourable
#> Allocation ratio                      equal group sizes
#> Statistical test assumed              unconditional comparison of 2 binomial proportions
#>                                         using the score test
#> Local or distant                      distant
#> Continuity correction                 no
#> Null hypothesis                       H0: pi2 - pi1 <= -0.05
#> Alternative hypothesis                H1: pi2 - pi1 > -0.05
#> 
#> Anticipated event probabilities       0.900  0.900
#> 
#> Alpha                                 0.050 (one-sided)
#> Power (designed)                      0.800
#>

#> Sample size per group (calculated)    457 457
#> Expected total number of events       822.60
#> Expected number of events per group   411.30 411.30
#> ------------------------------------------------------------------------------

A sample size of 457 is required in each group (914 total).

Superiority trial with multiple arms

artbin supports trials with more than two arms. Rather than comparing each treatment arm to control individually, it uses a global test for any difference among the groups.

artbin(pr = c(0.1, 0.2, 0.3, 0.4), alpha = 0.1, power = 0.9)
#> 
#> ART - ANALYSIS OF RESOURCES FOR TRIALS
#> ------------------------------------------------------------------------------
#> A sample size program by Abdel Babiker, Patrick Royston,
#> Friederike Barthel, Ella Marley-Zagar and Ian White
#> MRC Clinical Trials Unit at UCL, London WC1V 6LJ, UK.
#> ------------------------------------------------------------------------------
#> Type of trial                         superiority
#> Number of groups                      4
#> Favourable/unfavourable outcome       not determined
#> Allocation ratio                      equal group sizes
#> Statistical test assumed              unconditional comparison of 4 binomial proportions
#>                                         using the score test
#> Local or distant                      distant
#> Continuity correction                 no
#> 
#> Anticipated event probabilities       0.100  0.200  0.300  0.400
#> 
#> Alpha                                 0.100 (two-sided)
#>                                         (taken as 0.050 one-sided)

#> 
#> Total sample size (calculated)        176

#> Expected total number of events       44.00
#> Expected number of events per group   4.40 8.80 13.20 17.60

A sample size of 44 is required in each of the four groups (176 total).

Complex non-inferiority trial: the STREAM trial

The STREAM trial evaluated a shorter intensive treatment for multi-drug resistant tuberculosis against the lengthier WHO-recommended treatment. The design parameters were:

  • 70% favourable outcome probability on control, 75% on treatment
  • 10 percentage-point non-inferiority margin (\(m = \pi_2 - \pi_1 \geq -0.1\))
  • 1:2 allocation (twice as many patients in the treatment arm)
  • 20% loss to follow-up
  • Wald test (commonly used in non-inferiority trials)
artbin(
  pr      = c(0.7, 0.75),
  margin  = -0.1,
  power   = 0.8,
  aratios = c(1, 2),
  wald    = TRUE,
  ltfu    = 0.2
)
#> 
#> ART - ANALYSIS OF RESOURCES FOR TRIALS
#> ------------------------------------------------------------------------------
#> A sample size program by Abdel Babiker, Patrick Royston,
#> Friederike Barthel, Ella Marley-Zagar and Ian White
#> MRC Clinical Trials Unit at UCL, London WC1V 6LJ, UK.
#> ------------------------------------------------------------------------------
#> Type of trial                         non-inferiority
#> Number of groups                      2
#> Favourable/unfavourable outcome       favourable
#> Allocation ratio                      1:2
#> Statistical test assumed              unconditional comparison of 2 binomial proportions
#>                                         using the wald test
#> Local or distant                      distant
#> Continuity correction                 no
#> Null hypothesis                       H0: pi2 - pi1 <= -0.1
#> Alternative hypothesis                H1: pi2 - pi1 > -0.1
#> 
#> Anticipated event probabilities       0.700  0.750
#> 
#> Alpha                                 0.050 (two-sided)
#>                                         (taken as 0.025 one-sided)
#> Power (designed)                      0.800
#> 
#> Loss to follow up assumed             20 %
#> 
#> Total sample size (calculated)        398
#> Sample size per group (calculated)    133 265
#> Expected total number of events       233.48
#> Expected number of events per group   74.48 159.00
#> ------------------------------------------------------------------------------

A total sample size of 398 is required (133 control, 265 treatment), allowing for 20% loss to follow-up. When the STREAM trial concluded, it found that the shorter treatment was only 1% less effective than the WHO-recommended treatment, demonstrating significant evidence of non-inferiority.
